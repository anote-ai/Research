# Conference Submission Checklist

Use this checklist once per paper.

## 1. Paper Readiness

- [ ] Paper title is final enough for external sharing
- [ ] Author list is confirmed
- [ ] Natan and Spurthi are listed as co-authors
- [ ] Abstract is polished and under venue limits
- [ ] Main PDF is exported and stored in the repo
- [ ] Standalone paper repo is linked if one exists
- [ ] Figures, tables, and references are up to date
- [ ] Code repo or code folder is linked
- [ ] Reproducibility status is documented

## 2. Conference Submission

- [ ] Primary conference is selected
- [ ] At least one backup venue or workshop is identified
- [ ] Submission deadline is recorded
- [ ] Formatting matches venue rules
- [ ] Supplementary materials are prepared
- [ ] Ethics / broader impact section is included if required
- [ ] Anonymous vs. non-anonymous submission rules are checked
- [ ] Submission confirmation is saved

## 3. arXiv Readiness

- [ ] arXiv author list matches the paper
- [ ] PDF compiles cleanly for arXiv
- [ ] Source files are organized
- [ ] Abstract and category are ready
- [ ] Planned arXiv submission date is set

## 4. Website and Content Publishing

- [ ] `anote.ai/research` blurb is written
- [ ] Final paper link is ready
- [ ] Code link is ready
- [ ] Blog draft is ready for `anote.ai/blog`
- [ ] Medium adaptation is ready for `https://anote-ai.medium.com/`
- [ ] Talk deck is ready for `anote.ai/researchTalks`
- [ ] Social copy is added to the social tracking sheet

## 5. Intern Coordination

- [ ] Intern has been contacted directly
- [ ] Natan and Spurthi were CC'd
- [ ] Blockers are listed clearly
- [ ] Next action owner is assigned
- [ ] Stipend reminder for August 10 was communicated if needed

## 6. Central Repo Storage

- [ ] Paper lives under `researchpapers/<track>/`
- [ ] Standalone paper repo is linked in the release packet
- [ ] Code lives under `researchcode/` or linked repo
- [ ] Presentation lives under `researchpresentations/`
- [ ] Release packet is completed in `researchops/templates/`
