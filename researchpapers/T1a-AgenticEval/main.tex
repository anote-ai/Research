\begin{abstract}
\noindent
Existing benchmarks for tool-calling evaluate syntactic correctness --- whether a model produces a well-formed function call --- but fail to capture whether the model's actions align with the operator's intent in enterprise deployments. We introduce \textbf{EnterpriseBench}, a benchmark of 200 multi-step agentic tasks across four enterprise verticals (CRM, HR, DevOps, Finance), and a five-dimensional evaluation framework distinguishing syntactic accuracy from intent alignment. We evaluate five small language model (SLM) families (Qwen 2.5, Llama 3.x, Phi-4, Gemma 2, Mistral) under four prompting conditions. Our results show that BFCL leaderboard rank is a poor predictor of enterprise intent alignment, that model scale improves syntactic accuracy more than intent alignment, and that prompting strategy has a disproportionate effect on intent alignment. We release EnterpriseBench and all evaluation code publicly.
\end{abstract}
